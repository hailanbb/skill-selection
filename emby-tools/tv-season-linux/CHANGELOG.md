# 更新记录

## 1.1.1 — 2026-10-26

- 修复仅识别 `/home/tvflow-node/` 导致重复安装的问题，优先复用PATH、系统及当前账户nvm目录中的合格Node/npm。
- 安装依赖、构建、命令及后台服务统一使用所选Node绝对路径，不切换系统/nvm默认版本。
- Node合格但npm缺失时提示并停止，不重复安装Node；卸载继续保留Node。
- 增加运行时选择测试及Ubuntu复用/缺失两种安装卸载验证。

## 1.1.0 — 2026-10-26

- 新增统一安装/卸载入口；默认程序 `/home/tv-season-linux/`，Node独立位于 `/home/tvflow-node/`，卸载保留Node。
- 自动安装Node22并校验官方摘要，锁定依赖与构建；systemd环境自动启用本程序后台。
- 支持识别旧版命令/服务和源码位置，清理本机配置、任务记录、报告与日志；自定义共用输出目录只清理可追溯文件。
- 补缺保留默认站点，追加天空与观众，合并资源去重；站点未确认或搜索失败不降级提交。
- 归档后自动复核源清理、目标文件属性和报告集号/数量，Excel回读检查核验数据；异常标红并输出差异。
- 新增归档菜单 `5 复核归档报告与云盘（只读）`，支持完成后再次核查与导出。

## 未发布 — 2026-10-26

- 修正初检大小采集与当天播期判定差异，保留上游业务快照及测试。
