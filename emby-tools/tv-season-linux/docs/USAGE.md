# 中文菜单与实际流程

本文件描述已实现入口；DESIGN.md保留开发前完整设计，不代表其中每个可选增强已交付。

## 初检

`1 初检目录 → 1 浏览并选择检查范围`：通过API读取文件夹，输入数字进入，`s`选择当前范围，`m`批量选择子目录，`u`上级，`/`输入路径。批量输入支持 `1,3,5-8` 和 `a` 全部。也可从初检页直接输入范围路径。

根目录默认 `/115/Library_incs/nas/`；电视剧、动漫及更深分类均按实际层级发现，不写死地区名称。已选父目录会去掉重叠子目录，避免重复。支持明确Season N；无法确认季结构的目录写入待核实结果，不设置手工映射或作品身份绑定菜单。

确认范围后立即显示实时进度。总量未知时显示发现目录；确定后按作品显示进度。`1`暂停，`b`、`q`或Ctrl+C退出观看但后台继续。完成后可直接“按本次结果开始补缺”。

## 补缺和修复

`2 → 1 按当前初检结果开始补缺`：自动检查非绿/非紫季。显示工作流、数量与规则，输入“开始”确认本轮；之后自动选资源并提交，不逐剧勾选，不另有下载计划管理。

每季先重新读取实际文件和来源；搜索前及每次提交前查询现有下载，提交前再比较文件快照。已有任务范围不明、来源不明或提交结果不明不会重复下载。记录“已接受”不代表下载/整理已完成。

`2 → 3`检查整理阻挡，只读查询和预览；`2 → 4`显示具体修复清单，确认下载完成并输入计划编号后才删除指定历史、复制单集。`2 → 5`只读核实未知结果。原下载成功记录不会因为新一轮初检被清除。

## 复核清理

`3 → 1`读取当前工作流的季并复核实际文件；豆瓣通过MoviePilot查询，身份、季数或完结证据不足时暂缓。不以多个版本拼齐冒充一个完整版本。

`3 → 3`查看具体清理清单，完整列出保留文件、拟删文件与原因；输入 `执行 P编号` 才删除。多个完整版本仅列为人工处理，本版没有手工指定保留版本后强制删除的入口。

最多50文件一批，操作前后重新检查。部分成功持久保留已成功项；未知结果先用 `3 → 4`核实。仍存在的待删文件不会自动重发删除，需在远端确认在途操作状态；本版不提供一键清空防重日志。

## 归档

`4`顶部显示源根和归档根，`s`可设置目标；也可从 `8 → 2`设置。`4 → 1`只读生成归档清单，`4 → 2`展示后确认执行。

保留源根下完整相对分类路径。目标无同名作品时整部移动；已有同名作品则合入无冲突季和根文件。Season 1和Season 01视为同季；冲突整部暂缓。标准同名共用资料保留目标，源副本列入删除清单。全部内容及原目标核对后，源目录消失才标紫。

暂停后从 `5 任务与进度 → 继续`恢复同一任务；已验证移动不重发。响应丢失时先从 `4 → 3`只读核实；证据不足仍暂停。有未完成下载、修复或清理时不能归档。

## 任务、报告与设置

`5`查看任务，支持观看、查看结果及路径、暂停、继续、重新导出。`6`查看非绿色/非紫色问题项及原因；可按作品、路径、状态搜索。任务编号J、工作流编号W、待执行清单编号P分别独立。

`7`查看历史或导入没有外部操作历史的初检XLSX/本程序JSON。**导入只提取当前源根内的检查范围，并重新初检，不导入可执行请求，不覆盖现有防重日志。** 含下载/清理/修复/归档历史的文件拒绝仅作范围导入，应从原数据库或原流程继续；不能忽略其中的防重证据。不将旧报告颜色直接作为当前可删除/可移动证据；本版不承诺原XLSX人工样式/公式原样续写，原文件不改动，新报告另存。

`8 → 7`分别设置报告（Excel/CSV）、完整记录（JSON）和运行日志目录，可查看全部路径、检查可写性、恢复默认。设置持久保存；已有任务保持启动时的路径。

非TTY或 `NO_COLOR` 使用文字状态，命令行无TTY不自动确认写操作。时间审计为UTC，进度耗时用秒；本版播期和云盘显示时间统一按北京时间判定，未实现可变播期时区设置。

## 短命令

```bash
tvflow status
tvflow watch J编号
tvflow pause J编号
tvflow resume J编号
tvflow needs
tvflow doctor
tvflow export J编号
tvflow help
```

命令行执行写动作的入口保留在菜单的确认流程中，没有全局 `--yes`。源根临时覆盖、终端自动补全、多节点协同、定时自动执行与远端操作自动回滚未提供。
