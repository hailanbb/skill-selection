# 报告、记录与执行依据

程序以SQLite工作流和操作日志为主要记录，执行前重新核实远端事实。多份Excel/CSV不会被自动当作多个待执行任务，也不会按文件修改时间猜测应执行哪份。

同一工作流W关联初检、补缺、复核和归档任务J。由完成页继续时自动关联；从主菜单进入时，已有当前工作流就继续使用，无明确关联且有多轮记录时只选择一次工作流，不逐季选文档。界面始终显示当前W编号。

下载、清理、修复的关键日志按远端CloudDrive2地址和实际季路径保存；归档按作品路径保存。新检查轮次不会清除旧的未知操作记录。恢复从数据库读取，报告仅供查看和追溯。

## 自动输出

每阶段完成、暂停或捕获到失败时输出：

- Excel：任务统计、作品结果、操作结果；有清单时附文件清单。仅作品名称单元格着色。
- CSV：Excel每张表分别一个CSV文件，UTF-8 BOM、CRLF、规范引号，状态和原因以文字保存。
- JSON：本次任务、完整工作流、相关清单，保留长记录；凭据及私密下载入口剔除。
- 日志：逐步追加时间和进展，不含终端ANSI颜色码。

Excel超过单格长度的诊断详情明确提示查看JSON，不静默声称完整；CSV包含完整文本但不保留颜色和超链接样式。文件名包含阶段、J编号、时间和随机后缀，另存不覆盖旧文件。未知数量不写成0。CSV有公式形状的外部文本会加文本前缀，机器恢复以JSON/数据库为准。

默认位置：

```text
~/.local/share/tvflow/reports/J编号/   Excel、各CSV
~/.local/share/tvflow/records/J编号/   完整JSON
~/.local/share/tvflow/logs/J编号/      task.log
```

三类路径均可从 `8 → 7`分别更改。输出页展开为真实绝对路径，同时显示文件名。失败文件不列为保存成功，单独报告错误；数据库结果仍保留，可恢复目录可写性后从任务页重新导出。

在任务执行中强制断电不能保证最后一份报表已导出，但请求前持久操作日志仍用于防重复。重启后任务暂停，可查看并重新导出当前持久结果。

## 颜色

绿：已确认播完且齐全。蓝：有连载证据。黄：已接受下载、等待复核或其他待处理。红：无合格资源，原因不能与网络错误混写。紫：归档已实际验证。终端始终配文字，不仅依赖颜色。

## 导入

支持没有外部操作历史的初检XLSX和本程序 `tvflow/1` JSON，当前版本导入检查范围并重新初检。包含下载、清理、修复或归档历史的报告拒绝作为新范围导入，必须使用原数据库/原流程继续，避免忽略防重证据。CSV不具备完整流程记录，不作流程导入。导入不读取其中的下载URL或API请求体，不恢复其中的批准标记，也不覆盖当前数据库。

再次导入同一份文件可以建立新的检查轮次，但全局操作日志仍防止重复写入。旧报表不直接续写；原Excel人工备注和格式保留在原文件，新结果独立生成。
