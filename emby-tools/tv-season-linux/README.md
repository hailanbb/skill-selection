# 剧集整理Linux版

**v1.0.0 · Ubuntu / SSH · Node.js 22.13+**

在Ubuntu控制端通过API连接远端CloudDrive2和MoviePilot，完成电视剧、动漫的 **初检 → 补缺下载 → 复核清理 → 归档**，并提供旧整理历史阻挡修复。无需本机挂载媒体，无需浏览器操作，也无需AI服务。

输入 `tvflow` 打开中文数字菜单。启动任务自动进入彩色实时进度；退出菜单或断开SSH不会主动取消后台任务。支持root直接安装：root使用systemd系统服务，普通用户使用用户服务并启用linger，避免会话退出导致后台被系统清理。

## 菜单

```text
剧集整理Linux版
当前源根：/115/Library_incs/nas/

1 初检目录
2 补缺下载与整理修复
3 复核与版本清理
4 归档
5 任务与进度
6 待处理事项
7 报告与历史记录
8 设置与连接诊断
q 退出界面，后台任务继续
```

- **目录**：通过CloudDrive2 API浏览实际分类，可选择电视剧、动漫和多层子分类；默认源根 `/115/Library_incs/nas/` 可修改。设置归档目标在 `8 → 2`，归档页也有 `s` 捷径。
- **补缺**：关联当前初检工作流，自动确定对象；确认本轮开始后自动搜索、选资源并提交，不再次逐剧勾选，不设置独立下载计划菜单。
- **复核/清理/归档**：先只读检查，展示具体文件清单；输入 `执行 P编号` 才操作远端文件。多个完整版本保留为待人工处理，不自动选择并删除。
- **进度**：彩色状态、已处理/总量、当前作品和步骤、耗时、近期事件；总量未确定时不显示伪造百分比。清理/归档显示已核实文件或移动单元进度。
- **结束输出**：完成、暂停或可处理的失败后自动写Excel、各工作表CSV、完整JSON和日志，逐项显示真实文件名和绝对路径。
- **路径**：`8 → 7 报告与保存路径` 分别设置Excel/CSV、JSON、日志目录；修改影响新任务，旧任务保持原位置。
- **断点与防重**：SQLite保存工作流、任务、清单、批准和操作记录。重启暂停未完成任务，结果不明先核实，不盲目重发下载/删除/移动。

## 核心规则

不以文件数代替集号；不把混版拼齐当成独立完整版本；不把资源最高集号当作播出进度。资源先校验作品/季/覆盖，整季优先、明确中文标记优先、最低2做种，同等中文条件下≥5做种且容量全已知时优先小容量。

清理保护独立完整版本，仅删除已确认多余视频及唯一对应的图片/NFO，保留字幕和共用资料。归档核对同剧所有实际季；同季或未知同名文件冲突时整剧暂缓。目标标准共用资料保留，源重复资料明确列入删除清单，验证源路径消失才标紫。

动漫与电视剧使用同一流程。标准Season结构直接处理；没有明确季号、绝对集号与来源不一致、SP/OVA/特典等未知结构会列明原因，不提供手工季集映射或来源绑定菜单，不自动猜测、改名或删除。

## 快速开始

需要 **Node.js 22.13或更新版本**，root可直接安装。没有Node或版本太旧时，先按[Node安装命令](INSTALL.md#安装nodejsroot可直接复制)操作。下面只获取本项目及必要的Git元数据和少量索引，不下载其他工具正文：

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/hailanbb/skill-selection.git tvflow-source
git -C tvflow-source sparse-checkout set emby-tools/tv-season-linux
cd tvflow-source/emby-tools/tv-season-linux
bash install.sh
tvflow
```

先在 `8` 配置两个远端服务及认证，再进行只读诊断和小范围初检。安装脚本不替你配置账号、不修改远端设置，也不启动云端操作。后台服务与SSH长期运行方式见[安装说明](INSTALL.md)。

## 实现与边界

原业务规则来自本仓库油猴版的固定快照，**没有复用同仓库后端目录**。七个纯业务工厂由可核对的构建脚本生成；初检纯函数复用固定发布包的Node导出，不运行浏览器。已修正初检大小采集与当日播期规则不一致的问题。

CloudDrive2采用官方proto的gRPC或gRPC-Web，移动显式Skip冲突、不覆盖、不递归合并、不跨云移动。MoviePilot采用HTTP API；TMDB和豆瓣均经MoviePilot查询。公开接口存在不代表每个部署版本完全兼容，豆瓣返回数量也不代表本季已完结。

**真实CloudDrive2/MoviePilot写操作尚未验收**；测试均使用本地模拟服务和文件树。原有228项回归测试与本项目测试、Ubuntu CI范围见[验证记录](docs/VALIDATION.md)。视频内容、播放质量、字幕实际存在与文件哈希不在核验范围。普通删除能否恢复取决于远端存储，不承诺回收站或自动回滚。

归档流程不是远端原子事务，本程序锁不能阻止其他软件同时写入；每步比对变化并停止，但无法消除远端核对与操作之间的竞态。执行清理/归档时应避免其他程序向该作品写入。
