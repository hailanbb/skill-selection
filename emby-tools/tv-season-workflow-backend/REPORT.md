# 报告与操作追溯

[项目首页](README.md) · [接口与使用](docs/API.md)

报告一季一行；颜色表达阶段状态，不能代替实际目录核验。数据库保存操作前快照、计划hash、提交记录及核实结果。

| 输出 | 用途 |
|---|---|
| GET /reports | JSON季信息、公开计划和任务结果；下载上下文按白名单脱敏 |
| GET /reports.xlsx | 当前数据库的初检/状态快照；不是原表的保留式更新 |
| POST /reports/import | 以base64导入原工作流XLSX，不启动外部写操作 |
| GET /reports/:id/xlsx?mode=download | 更新已完成下载阶段结果，保留原备注、公式、链接、其他表和历史明细 |
| mode=review / mode=archive | 对应复核清理与归档结果更新 |

原表需要与当前服务地址、源目录、季路径一致，重复季行和不支持的格式会拒绝。数据库已存在同路径季时，不通过导入覆盖已有记录。完整请求格式见接口文档。

下载accepted只代表请求确认，黄色仍需等待实际文件。清理记录区分计划、提交、结果未知和已验证；归档源共用资料删除单独记录，不冒充移动成功。

SQLite位于DATA_DIR/workflow.sqlite。备份时停服务或使用SQLite备份机制，不能漏掉WAL。内部数据库含执行所需私密资源上下文，按个人资料保管；不要上传到公开仓库。
