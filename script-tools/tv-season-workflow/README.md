# 剧集初检与补缺下载

两个独立的 Tampermonkey 用户脚本：先在 CloudDrive2 检查缺集，再把 Excel 交给 MoviePilot 补充下载。普通使用无需 Node.js、Python、AI 服务或命令行。

| 脚本 | 当前版本 | 在哪里使用 | 会执行什么 |
| --- | --- | --- | --- |
| [① season-inspect.user.js](season-inspect.user.js) | **1.1.1** | CloudDrive2；需要时读取豆瓣 | 只读目录，按季核对，导出报告。不移动、删除、重命名文件，不创建云端目录。 |
| [② season-download.user.js](season-download.user.js) | **1.2.0** | MoviePilot | 导入报告后，点击“开始补缺下载”才向默认下载器提交下载。不修改云盘文件，不创建订阅。 |

**安装后默认不运行。第二脚本的“开始”会实际提交下载。** 本目录只发布第一、第二阶段，不包含删除清理或归档脚本。

## 第一次使用，照这个顺序做

1. 按 [安装教程](INSTALL.md) 安装两个脚本，填好自己的站点地址和源目录。
2. 打开 CloudDrive2，在第一脚本中填写自己的 TMDB 访问设置，测试连接。
3. 点击“读取分类”→选择分类→“开始检查”。也可先手动进入一部剧，点击“检查当前剧集”。
4. 扫描完成后若显示“豆瓣待补查”，准备好豆瓣访问后，手动点击“仅补查豆瓣待处理项”。显示的下次可尝试时间不是自动启动时间。
5. 点击“导出 Excel（绿 / 蓝标记）”，保存 `.xlsx` 文件。可手工核对、填写备注；已确认齐全的季可将“剧集目录”格标为浅绿底、深绿字。
6. 打开 MoviePilot，在第二脚本点击“导入 Excel”，选择这份报告。**导入只排队，不下载。**
7. 确认任务数量后点击“开始补缺下载”。结束或暂停后点击“导出更新报告”。
8. 在新报告的“下载明细_N”中查看每个资源的站点、做种数、容量、中文标记、覆盖集号、任务 ID 和执行结果。等待 MoviePilot 下载及后续整理完成；黄色不能当作“文件已齐全”。

## 目录与报告约定

```text
源根目录，例如 /115/Library_incs/nas/电视剧
└── 韩国剧集                     ← 手动选择的分类
    └── 示例剧 (2025) [tmdbid=123]
        └── Season 1
            ├── 示例剧 - S01E01 - 01.mkv
            └── 示例剧 - S01E02 - 02.mkv
```

目录中的 TMDB ID 应为真实电视剧 ID，示例 `123` 只是占位。每个报告行对应一季。季号、目录路径、来源数量和源链接会共同用于后续定位，不能仅靠剧名猜测下载对象。

| “剧集目录”格颜色 | 含义 |
| --- | --- |
| 浅绿 `C6EFCE` / 深绿字 `006100` | 当季确认播完、集号齐全且无待处理异常，或人工确认。第二脚本跳过。 |
| 浅蓝 `BDD7EE` / 深蓝字 `1F4E78` | 有本季仍在播出的证据；已播部分仍可能缺集。 |
| 黄色 `FFFF00` / 黑字 | 已提交下载或确认已有任务，等待实际下载和复核。 |
| 浅红 `FFC7CE` / 深红字 `9C0006` | 未找到合格匹配资源，或匹配资源做种不足 2。 |
| 浅紫 `E4DFEC` / 深紫字 `7030A0` | 已归档标记；第二脚本跳过。本次两个脚本不会执行归档。 |
| 无填色 | 缺集、来源不明或其他待核实情况，阅读说明列。 |

只改变“剧集目录”单元格的阶段颜色，不给整行统一染色。第二脚本保留原备注、无关公式、链接和旧明细页，另存新文件；Excel 文件不会在磁盘上自动被更新。

## 下载优先级

1. 必须匹配电视剧身份、具体季号和明确集号，最低做种数 **2**。
2. 合格整季包优先，没有时才补零散集。本轮已有成功提交的集目时，只补剩余集目，避免又下载整季。
3. 同类资源优先明确中文标签/字幕或配音标记。仅片名含汉字不算字幕证据；无中文资源时允许其他合格资源。
4. 同等中文条件下，优先从做种 **≥5（含5）** 的资源中选择。这些候选容量均已知时，整季比较总容量，零散集比较每个待补集的估算容量；较小者优先。
5. 没有≥5做种候选，或高做种候选存在未知容量时，按做种数从多到少选择。未知容量不是零。详见 [完整选择规则](docs/02-download.md)。

## 维护者构建与测试

普通安装只需要两个 `.user.js`，无需下载 `src`、`vendor` 或执行以下命令。开发者使用 Node.js 20 或更新版本，在本目录运行：

```sh
npm install
npm run build
npm test
```

`src/` 为有中文注释的维护源码；`build.cjs` 将内置的 OpenCC 和 Excel 库嵌入两个安装脚本，运行时不访问 CDN。`test/` 包含 80 项发布包回归测试，测试不会向真实 MoviePilot 提交下载。依赖及许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。

公开版使用示例地址，把需要修改的常量放在脚本开头。更新脚本前先导出报告并记下自己的地址/路径；用新版覆盖后需要重新填入这些源码配置。TMDB 凭据和防重复记录使用各自脚本存储，不要通过清空存储解决下载结果不明的问题。

验证覆盖本地逻辑、模拟页面及 XLSX 读写。公开地址配置版尚未在不同部署环境做真实端到端验证；CloudDrive2 页面结构和 MoviePilot 页面 API 必须与本版适配一致。下载器目标目录沿用 MoviePilot 现有配置，脚本不会把报告源路径强行设为下载目录。
