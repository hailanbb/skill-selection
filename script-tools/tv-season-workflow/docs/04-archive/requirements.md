# ④ 剧集归档 · 需求

[项目首页](../../README.md) · [安装](install.md) · [使用](usage.md)

| 项目 | 规则 |
| --- | --- |
| 输入 | 导入含绿色项的报告，只排队；点击开始/继续检查后读取云盘 |
| 范围 | 同一剧集所有实际季必须各自唯一对应绿色行；混色、漏季、重复行、未知子目录等不能直接归档 |
| 预检 | 检查集号连续、报告数量、重复视频、文件大小及下载临时文件；目标根目录与同名分类必须已存在 |
| 新剧 | 目标分类没有同名剧集时，移动整剧目录及配套文件 |
| 同名剧 | 目标已有完全同名剧集时，只移动目标缺少的季；源根部共用资料保留 |
| 同季冲突 | 目标已有同季（含 Season 1 / Season 01）则跳过并输出明细，不覆盖；其他合格缺季可继续 |
| 执行 | 先列清单，用户点击执行并确认后移动；每次提交前持久保存操作记录 |
| 验证 | 核对移动单元、目标原有内容及源端应保留内容；以界面路径、类型、大小和修改时间为依据 |
| 中断 | 结果不明只读核实，不自动重复移动；保留各项已完成/未完成状态 |
| 输出 | 归档验证成功的季标紫色，冲突跳过保留原色；逐文件列出原路径、目标路径、状态及错误 |

示例：源“天龙八部 / Season 2”，目标“天龙八部 / Season 1”——把 Season 2 移入目标同名剧集。若目标已有 Season 2，则跳过第二季并记录冲突。

不做模糊剧名合并，不创建缺少的目标分类，不覆盖同名文件，不清理源端剩余的空目录。遇到界面要求覆盖、复制或额外冲突确认时停止。
