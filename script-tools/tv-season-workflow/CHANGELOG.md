## ① 初检 v1.1.1

- 默认不运行，按修改时间逐剧逐季只读检查；空季记0/0，来源未知不伪造0。
- TMDB 主查、豆瓣按需复核；简繁中文/日文/韩文/英文标题和别名校验。
- 豆瓣分季缓存、逐页限速、访问预算、失败退避、风控冷却及人工恢复。
- 保存进度，手动恢复/补查；Excel 绿/蓝状态与完整诊断。
- 路径编辑框打不开时有限重试，持续失败暂停当前剧；未查询来源不误显示豆瓣。

## ② 下载 v1.2.0

- 导入只排队，手动开始；精确匹配媒体、季号及集号，检查已有任务并持久防重复。
- 整季优先，允许零散集补缺；最低2做种，同类中文标记优先；≥5做种且容量可确认时优先小容量。
- 零散多集按每个待补集估算容量；选择后重算剩余集目，未知容量不当作零。
- 下载明细逐资源记录站点、做种、类型、集号、任务ID、时间、容量、中文标记与选择依据。
- 未选定资源时做种数明确显示“未选定资源”；已有任务只有标题及站点唯一对应时才引用本轮搜索做种数，并说明不是创建任务时的值。
- 原报告备注、公式、链接与历史明细保留；长机器记录分片保存。

## 构建与维护

普通用户按 INSTALL.md 安装即可。维护者修改 src 后运行 `npm run build`，再运行 `npm test`。只修改生成文件会在下次构建时丢失修改。

旧综合版仍保留在 `../clouddrive2-season-audit/`，不要与新初检脚本同时启用。升级前先保存报告和个人地址配置，公开版不会自动保留手工改写的源码常量。
