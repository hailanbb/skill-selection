## 面板拖动与右下角停靠：初检 v1.1.2 / 下载 v1.2.2

按住面板标题栏可拖动，展开和收起状态均可移动。点击“收起”时自动停靠页面右下角；点击“展开”恢复收起前的展开位置。收起后可再次拖走，但下次点击收起仍会重新停靠。各脚本分别记住位置和收起状态，窗口缩放时避免面板超出可视区域。收起只隐藏界面内容，不暂停、启动或取消任务；点击按钮不会触发拖动。

新增共用位置控制模块和5项回归测试，发布包共85项通过。独立Chrome中加载完整脚本，验证拖动、收起停靠、展开恢复、窗口缩放和刷新恢复；没有请求真实业务接口。原下载/来源规则不变。

## 构建与维护

普通用户按 INSTALL.md 安装即可。维护者修改 src 后运行 `npm run build`，再运行 `npm test`。只修改生成文件会在下次构建时丢失修改。

旧综合版已从当前目录移除；安装新阶段前请停用浏览器中的旧综合版。升级前先保存报告和个人地址配置，公开版不会自动保留手工改写的源码常量。
