# 🧰 脚本工具 (Script Tools)

本目录用于收录通用独立脚本、自动化运维与便捷批处理工具，可脱离 Agent 环境在 Linux/Windows 物理机或服务器上独立执行，亦可作为系统守护进程常驻后台：

| 工具名称 | 核心功能 | 触发场景 | 详细说明 |
| :--- | :--- | :--- | :--- |
| **TG -> 115 定向云下载 (`tg-to-115`)** | 监听 Telegram 资源频道，按出演者多语言别名白名单过滤；支持多频道独立断点续传、真实消息结构探测、跨盘秒传归并（快捷键 `m`），通过 CloudDrive2 gRPC 自动轮转多 115 账号执行纯云端离线下载，零本地带宽与磁盘消耗。 | Telegram 资源自动转存 115、多 115 账号配额轮转、跨云盘自动归并、频道消息结构兼容性测试。 | [👉 安装与使用指南](tg-to-115/README.md) |
| **PikPak 影视极速整理** | 基于 PikPak 官方 API 的 15 并发极速影视整理与广告清理。支持番号智能识别（含 FC2/长番号兼容）、女优名中文化、版本后缀保留、冲突智能防覆盖、广告特征词强拦截、以及旧目录清空与垃圾文件安全移入云端回收站。 | PikPak 网盘极速整理、博彩/宣传垃圾短片清理、按演员建立目录并重命名归档。 | [👉 详细配置与使用指南](../skills/pikpak-video-organizer/README.md) |

*(未来新增的独立脚本与运维工具将持续罗列于上表中，并对应放置于当前目录下。)*
