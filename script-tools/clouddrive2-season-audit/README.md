# CloudDrive2剧集整理助手 · 只读核对版

**版本：v0.5.0** · **环境：Chrome + Tampermonkey + CloudDrive2**

手动选择一个电视剧分类，按修改时间从旧到新逐剧、逐季核对集号。优先按目录中的 TMDB ID 查询；TMDB 不可用或结果为“未完结”时使用豆瓣，导出本轮缺集报告。安装后默认不运行，**本版不移动、删除、重命名文件，也不创建云端目录**。

[安装脚本](season-audit.user.js) · [返回脚本工具](../README.md) · [返回个人开发](../../README.md)

## 🧩 功能与处理范围

| 功能 | 处理规则 |
| :--- | :--- |
| **指定分类检查** | 从临时目录读取分类，选一个后开始；该分类完成即停止。也可只检查当前打开的剧集。 |
| **按季核对** | 识别 `Season 1` 等季目录及 `S01E01`、`第12集`、`EP12`、纯数字文件名，核对完整集号集合。 |
| **TMDB 主查** | 从剧集目录名中的 `[tmdbid=数字]` 查询对应季；校验 ID、季号、连续集目与数量。 |
| **豆瓣备用与复核** | TMDB 无可用信息时备用；TMDB 结果明确为“未完结”且目标不重名时再次复核，最终按豆瓣重算集数和缺集。 |
| **重名保护** | 目标分类有同名剧集时标记“目标重名”，不合并、不覆盖。 |
| **可拖动面板** | 展开与收起都可拖动；同一页面可暂停、继续本轮。 |
| **报告导出** | Excel、CSV、完整 JSON；Excel 中最终齐全记录的“剧集目录”单元格填绿。 |

字幕、NFO、海报不计入视频；`.strm` 计为视频指针，但不验证内容能否播放。不支持同集多版本、上下集合并或特别篇。未知集号、重复、越界、季内子目录等进入待核实，不按文件数量直接判齐全。

### 完结状态与豆瓣复核

- TMDB 没有未来、当天播出或日期未知集目，且全剧状态为 `Ended` 或末集带 `finale` 标记，才允许根据集号判定齐全／未完结；否则为“待核实”。
- 只有 TMDB 的“未完结”触发新增豆瓣复核；“待核实”“齐全”“目标重名”不触发。
- 豆瓣复核成功后，报告总集数、缺失集号、来源链接及结果以豆瓣为准。匹配失败或没有有效总数时为“待核实”，原 TMDB 证据保留在 JSON 的 `review` 字段。
- 豆瓣支持简繁双标题、年份／首播年份核对；后续季必须明确匹配季号。登录或验证需手动完成，不绕过验证。
- “齐全（未移动）”只表示检查结果，不能当作已归档。

## ⚙️ 第一阶段：环境自检与首次使用

1. Chrome 安装 Tampermonkey，并按扩展提示允许用户脚本执行。确认可以手动打开 CloudDrive2 文件列表。
2. 打开 [season-audit.user.js](season-audit.user.js)，点击 GitHub 的 **Raw** 查看完整内容；在 Tampermonkey 新建脚本并用完整文件替换默认内容。
3. 发布版使用示例地址，**必须修改以下两处**：

   ```javascript
   // @match        https://clouddrive.example/*
   const CLOUD_ORIGIN = 'https://clouddrive.example';
   ```

   `CLOUD_ORIGIN` 填实际协议、主机与端口，不带末尾 `/` 或目录路径。例如 `https://cloud.example:8920`。`@match` 按 Tampermonkey 匹配规则填写对应协议和主机，如 `https://cloud.example/*`；脚本内部还会校验完整 origin。不要改成匹配所有网站。豆瓣相关匹配行保持不变。

4. 如目录布局不同，修改这两项（脚本路径不带页面显示的 `Root` 前缀）：

   ```javascript
   const SOURCE = '/115/Library_incs/nas/电视剧';
   const DEST = '/115/Library_incs/nas.finish/电视剧';
   ```

   源和目标使用同名分类，剧集目录应含 `[tmdbid=数字]`，季目录为 `Season N`。

5. 保存并刷新 CloudDrive2 页面，只启用一份脚本。在面板填写自己的 **API 读访问令牌**和／或 **API 密钥**，保存后测试 TMDB 连接。都填写时优先令牌，认证失败时尝试密钥。
6. 可先点“打开豆瓣／登录准备”，手动完成必要的登录和验证，回面板勾选“豆瓣已可访问”。尚未准备时，脚本会在需要豆瓣时暂停，准备后再继续。

普通安装不需要 Node.js、Python 或 AI 服务。简繁转换和 Excel 导出库均内置。凭据只保存在当前脚本的浏览器设置中，不写入报告；发布文件不含个人站点地址、凭据或扫描记录。

TMDB 官方说明：[认证](https://developer.themoviedb.org/docs/authentication-application) · [季详情](https://developer.themoviedb.org/reference/tv-season-details)。This product uses the TMDB API but is not endorsed or certified by TMDB.

## ▶️ 第二阶段：核心工作流

| 操作 | 使用方式 |
| :--- | :--- |
| **检查一个分类** | 点击“读取分类”，选择目标分类，再点“开始检查”。按修改时间升序读取完整列表并检查。 |
| **检查单部剧集** | 在 CloudDrive2 打开某剧或某个 Season 目录，点击“检查当前剧集”。 |
| **暂停与继续** | 点击“暂停”；处理登录或页面问题后点击“继续本轮”。仅当前页面有效。 |
| **保存报告** | 完成后点“导出 Excel（绿色标记）”“导出 CSV”或“导出完整 JSON”。 |

保持 Chrome 和工作标签页打开，避免电脑休眠。可浏览其他标签页，但 Chrome 后台节流、冻结或丢弃页面可能拖慢或中断运行；不能保证最小化后不受影响。运行时不要手动切换同一云存储工作页目录。

**刷新或关闭页面会清空本轮结果与进度。** 本版没有本地剧集数据库、历史报告或跨刷新恢复；旧版存储不读取也不删除。面板位置、分类选择与 TMDB 设置仍保留。

### 报告怎么看

- Excel 与 CSV 保留相同的 17 列：分类、剧集目录、季数、源云存储链接、视频文件数、已识别集数、来源登记集数、缺失集号、数据来源、集数核对、目标重名、处理结果、目标路径、来源链接、来源查询时间、豆瓣候选标题、详情标题。
- Excel 设置列宽、换行、筛选和原生超链接，仅“齐全”／“齐全（未移动）”记录的剧集目录填绿。CSV 无法保存颜色。
- CSV 使用 UTF-8 BOM、CRLF；源云存储链接为 `HYPERLINK` 公式，Excel/WPS 的导入设置可能影响点击效果。
- 目标重名只在重名时显示 `YES`；缺失集号“未确认”表示暂不能计算，“无”表示已核对范围内不缺集。
- JSON 包含详细诊断和队列，不含凭据。面板仅显示最近 100 项，导出包含本轮全部结果。

## 🛠️ 排障、更新与卸载

| 情况 | 处理 |
| :--- | :--- |
| 面板未出现 | 核对 Tampermonkey 执行权限、`@match` 与 `CLOUD_ORIGIN`，保存后刷新。 |
| TMDB 连接失败 | 检查凭据和网络；需要时允许脚本访问 `api.themoviedb.org`。 |
| 豆瓣登录／验证或无响应 | 手动处理对应标签页，确认脚本可在豆瓣运行，回面板确认准备完成并继续。 |
| 本地集数等于 TMDB 仍待核实 | 检查 TMDB 是否仍连载、末集未标季终，或有未来／未知日期；当前登记数不等于最终总数。 |
| 页面条目不全或结构变化 | 不按不完整列表继续判断；按提示暂停，核对页面与版本兼容性。 |

更新前导出本轮结果，再用新安装文件替换旧脚本，重新填写发布版示例站点配置后保存并刷新。不要上传个人配置或报告。卸载时在 Tampermonkey 禁用／删除脚本；已下载报告由用户自行保管。
