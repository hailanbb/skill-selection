# Agent 自动执行说明

这些命令由 Agent 内部执行，不要求用户制作 JSON、运行命令或复制摘要值。自然语言提炼由 Agent 完成，脚本承担可验证的配置、检索与文件操作。

## 工具路径与依赖

先定位当前 Skill 的真实安装目录，以下路径均相对于它；不得假定本机用户名、工作区或某个厂商的安装路径。Python 工具要求 3.10+；`requirements.txt` 为 PyYAML 6.x。优先使用已有环境，依赖缺失时按当前权限在独立环境准备，不擅自改全局环境；不能运行脚本时使用具备同等保障的文件工具。

## 读取与初始化配置

```sh
python scripts/configure.py show
```

没有配置返回 `needs_setup: true`，此时先向用户询问完整归档路径。不要自动调用 setup 使用某个示例。用户给出路径后：

```sh
python scripts/configure.py setup --destination "/absolute/vault/任务与经验"
```

自动向上找 `.obsidian`；无法定位时让用户补充根目录，再加 `--vault "/absolute/vault"`。setup 只保存配置，不创建归档目录或笔记。已存在不同配置会拒绝；用户明确说更换长期路径时加 `--replace`。第一次明确提供路径后无需重复询问是否保存配置。

配置按 `--config` > `TASK_MEMORY_CONFIG` > `~/.config/task-memory-to-obsdian/config.json` 定位；所有 Agent 可共享。schema 为：

```json
{
  "schema_version": 1,
  "vault_root": "/absolute/vault",
  "archive_root": "任务与经验"
}
```

配置不含秘密、不放进归档笔记或公共仓库。无配置存储能力时只在当前上下文复用，报告无法跨会话记住，不把“可记忆”当成“已持久化”。配置路径失效时 show 返回错误与 needs_setup；恢复正确路径或请用户提供新路径，不能自行猜测。

## 只读候选检索

```sh
python scripts/recall.py --query "项目关键词" --limit 5
python scripts/recall.py --task-id "已知任务ID" --limit 5
```

只遍历归档区的 Markdown 元数据，输出候选路径、summary、日期与类型；不把所有正文读进模型。可用 `--type lesson` 查避坑卡，`--type prompt` 查提示词。没有归档目录视为尚无记录。读取失败/格式异常单独报告，不冒充零问题。

按多个有区分度的词搜索并审阅相关性，不因纯字符串命中自动合并任务；必要时换词或查看少量候选全文。该工具是关键词召回，语义判断由 Agent 承担。

## 自动写入

Agent 在库外独立临时目录生成 UTF-8 JSON：

```json
{
  "notes": [
    {"path": "会话/2026/09/20260910-100000-任务-a1b2.md", "content": "符合 note-format.md 的完整 Markdown 正文及 YAML"}
  ]
}
```

notes.path 相对于用户选定的保存区。工具从共享配置取得库根和保存区；正文双链相对于**库根**。确认所有草稿语义、脱敏与链接之后：

```sh
python scripts/save_notes.py /temporary/notes.json --auto
```

`--auto` 在内部预检成功后自动生成摘要并提交、回读，无用户摘要步骤。它代表调用者已处理本次真实授权，不是绕过平台权限的开关。用户要求预览或适用规则必须等待确认时，不加 `--auto`；工具默认只预览，待确认后 Agent 内部调用 `--apply --expect <返回摘要>`。

单次路径覆盖：用户明确要求“这次存到……”时，生成完整清单 `{"vault_root": "...", "archive_root": "...", "notes": [...]}`。这优先于配置且不修改配置；先核实该次路径来自用户。初始化没有持久成功时也可用这个形式完成本次归档，并如实报告记忆缺口。

## 防覆盖与失败处理

保存工具拦截越界、符号链接/目录连接点、非法文件名、无效属性、失效双链和既有内容冲突。相同目标相同字节视为安全重试，不重复写；不同内容不覆盖。Agent 可为**未提交的新草稿**生成新唯一后缀并更新草稿关联；不能重命名已有页。

每页先写同目录临时文件，再通过硬链接无覆盖提交，要求本地文件系统支持硬链接。不支持时工具返回明确错误，Agent 可选择等价的原生仅新建机制；无法确保完整写入和保护旧文件则交付草稿并说明具体缺口。

批量提交不是整体事务：部分失败保留已提交项并列出它们。重试前核实状态；同一清单可跳过已完成项补齐剩余页，整批完成前跨页链接可能暂不可用。不能删除旧文件以便重试；不支持攻击者并发替换目录的共享路径。常规可修复错误最多两次重试，明确权限/路径阻塞及时报告。

支持库根相对、无标题/块锚点的双链，代码围栏内示例双链不解析。需要锚点时用更强工具核对，或在新草稿采用文件级链接，不能跳过检查冒充已通过。工具不替代内容真实性、脱敏与语义审查，也不会运行笔记中的代码。
