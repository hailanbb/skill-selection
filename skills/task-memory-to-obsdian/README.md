# Task Memory To Obsdian

对 AI 说 **“帮我归档到obsdian”**，把当前任务中值得保留的上下文与经验，自动保存到你的 Obsidian。支持通用 Agent，按用户指定保留名称中的 `Obsdian` 拼写。

## 使用体验

**首次使用**：Agent 会先问“你希望把归档内容保存到 Obsidian 的哪个文件夹？请给我完整路径。”你回答后，它会记住路径，并接着完成这次归档。如果无法自动识别库根，才补问库根在哪里。

**以后使用**：说同一句口令即可。Agent 自动分析当前对话、提炼、命名、分类、查重、建立关联、新增笔记、回读验证，最后给你笔记链接。你不需要选择模板、决定卡片数量、制作清单或运行命令。

**更换路径**：说“以后归档改存到……”。只说“这次存到……”则仅覆盖这一次，长期默认不变。没有用户初始化的路径不会从设计文档里自动启用。

**下次接着做**：把归档完成时给出的续接口令交给新 Agent，它会读取记录并核实当前状态；也可以说“从归档里找上次某项目的记录，恢复上下文”。

## 智能归档什么

| 产物 | Agent 自动判断的内容 |
| --- | --- |
| 交接快照 | 背景、问题、尝试、结论、可复用要点，以及目标、验收、当前状态、阻塞、下一步和证据。 |
| 决策卡 | 关键选择、真正讨论过的备选方案、可见理由、代价与重新评估条件。 |
| Prompt 卡 | 可复用提示词、输入变量、输出要求、适用场景和实际测试范围。 |
| 代码卡 | 可复用代码/命令、环境与依赖、输入输出、副作用和验证证据；保存不会执行。 |
| 避坑卡 | 症状、失败尝试、已确认原因与假设、处理办法、适用边界和复发检查。 |

通常一份快照就够；只有能独立复用的内容才拆卡。没解决的任务也能保存，未知就记录未知。已有同等经验优先引用，有新进展或修正则新增后继记录，不覆盖旧笔记。

## 首次路径与目录

没有预置用户机器路径。你可以选择库内任意合适的专用归档子目录，例如 `任务与经验`。Agent 在选定目录中按需创建：

```text
你选定的归档目录/
  会话/年/月/时间-任务名称-唯一后缀.md
  经验/决策/...
  经验/提示词/...
  经验/代码/...
  经验/避坑/...
```

详细职责与取舍见 [目录设计](references/storage.md)。路径配置保存在本机 `~/.config/task-memory-to-obsdian/config.json`，或环境变量 `TASK_MEMORY_CONFIG` 指定的位置。各 Agent 读取同一普通 JSON 即可复用；跨机器需重新选择该机器的实际路径。私人配置、笔记和临时清单不提交到 GitHub。

## 通用 Agent 安装

1. 将整个 `skills/task-memory-to-obsdian/` 文件夹复制到目标客户端**实际支持的** Skill 目录；不同客户端的安装目录由其自身决定。
2. 若客户端没有 Skill 机制，让它读取本包 `SKILL.md`，并按其中链接按需读取引用文档。中文触发口令在 description 和正文中都有说明。
3. 有文件读写工具即可实现归档；支持运行 Python 时可以使用随包工具自动完成路径配置、检索、预检和防覆盖写入。不要求 Codex、Claude、Gemini、Hermes 等任何一家专有接口。

| Agent 能力 | 使用方式 |
| --- | --- |
| 能读取技能、执行 Python | 按 Skill 自动调用配置、检索和保存工具。Python 3.10+，写入校验用 PyYAML 6.x；在授权的独立环境准备依赖。 |
| 有原生文件工具/文件连接器 | 用同一套指令和数据格式；工具须支持仅新建、校验与回读。若无法保证防覆盖，就交付草稿并说明限制。 |
| 只有聊天能力 | 可以完成提炼与草稿，不能直接访问用户磁盘；如实说明尚未保存。 |

工具命令放在 [Agent 执行说明](references/runtime.md)，日常用户无需操作。配置仅存位置，不借助厂商记忆；因此可在多个具备本地权限的 Agent 间共用。不同沙盒能否访问主库仍取决于实际权限，不能只凭安装就声称全部平台实测兼容。

## 自动化与已有笔记保护

“帮我归档到obsdian”是本次自动新增归档的请求。常规预检由 Agent 内部完成，不默认逐篇弹出确认。若你特意要求“先预览”，或实际库/平台明确要求确认，才按要求停下；不修改这些规则来获得权限。

已有笔记、索引、首页与源文件永不原地修改；重复记录复用，更新和纠错新建后继页。个人信息按必要范围提炼、秘密脱敏，不上传私人对话到 GitHub，不自动关闭平台会话，也不运行归档的命令或代码。

## 验证与迁移

开发者可运行 `python -m unittest discover -s tests -v`。覆盖首次配置、跨进程复用、单次路径与默认路径、中文读写、防覆盖、越界、目录连接点、断链、部分失败重试和只读检索；内容决策验收见 [行为场景](references/acceptance.md)。结构测试不能代替真实任务的语义核对。

旧版名称为 `obsidian-task-memory`。新版目录为 `task-memory-to-obsdian`，入口标题为 **Task Memory To Obsdian**；替换旧安装时按客户端机制处理，避免同时启用重复技能。旧版没有持久路径配置，新版首次实际归档会重新询问。既有归档笔记格式保持可读，不迁移或修改历史文件。
