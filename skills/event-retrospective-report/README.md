# 商业活动高管复盘长网页制作技能 (Event Retrospective Report)

面向企业最高管理者（老板、总裁办、合伙人）汇报线下商业活动、推介签约会、招商会销、客户沙龙或行业峰会战果的专用复盘生成技能。

交付成果为专为**手机竖屏浏览（钉钉/微信）优化的单文件长网页（HTML）**，彻底打破传统幻灯片（PPT）在移动端排版臃肿、需要多层翻页、文字密密麻麻的弊端；采用 **XKONG 科技深蓝高管视觉** 与 **微软雅黑**，并支持将现场实拍照片全额通过 Base64 编码内嵌，做到**零外链、断网秒开、全员绝不裂图**。

| **向老板汇报活动成果** | “我们要向老板汇报这次峰会的战果与转化漏斗” |

## 🏗️ 八大高管标准汇报模块

```text
├── 模块一：封面与活动概览（时间节拍、精确地点、专场定位）
├── 模块二：核心转化战报看板（3大核心指标卡：报名数、实到数、意向签约数与转化率）
├── 模块三：本次活动的核心战略意义（战略大盘首站、验证快速签约闭环、内振士气外树标杆）
├── 模块四：亮点表现与现场热烈反响（新秀表扬、反响最热烈的核心环节）
├── 模块五：高潜观望客户的核心关注与转化契机（婉转、客观、保护团队士气）
├── 模块六：现场问题反思与专题研讨安排（客观反思 + 会后组织团队专题研讨）
├── 模块七：中后台协同支持诉求（宏观赋能面：所见即所得、真实样板、OCR攻坚）
└── 模块八：下阶段推进方向（简明几句话） + 现场纪实剪影（纯净大图、Base64内嵌）
```

## 🎯 高管沟通心理学与表达红线

1. **三秒定心，成果前置**：
   - 首屏必须是“高管驾驶舱”，3 秒内通过最核心的数字卡片（到场率、签约数、现场转化率）建立胜势感知，绝不让高管在长篇文字中翻找结果。
2. **算清大账，克制细节**：
   - 商业模式只讲“谁买单、凭什么增收、几天抵销投入”，**严禁堆叠底层复杂的机械数学假设公式（如天数×单价×分润百分比）**；不主动罗列零散的微观财务杂支与单客获客成本（CAC），除非明确要求。
3. **呵护士气，婉转表达客户疑虑**：
   - 将未现场签约的客户准确定位为“严谨求实的高潜储备客户池”，从技术采纳曲线、医者理性审慎、政策信息差等客观规律切入，既客观呈现顾虑，又为后续转化指明抓手，全力保护一线团队士气。
4. **肯定新人，提振组织活力**：
   - 主动点名表扬首次登台担纲核心产品演示与商业宣讲的新秀同仁，向管理层展示团队梯队建设与人才活力。
5. **中后台诉求讲宏观，不陷入单点抱怨**：
   - 聚焦展示产品所见即所得、跑通真实场景树立样板客户、核心难点（如纸质 OCR 识别）攻坚三大宏观维度，强化跨部门协同合力。
6. **现场问题客观陈述，不自作主张**：
   - 坦诚列出开场迟到、设备瘫痪、翻页笔/签约笔缺失、讲稿现场打印等真实问题；但文末统一表述为“会后将统一安排相关团队召开专题研讨会，制定系统性改进措施”，体现组织严谨性。

## 🎨 视觉设计规范 (XKONG 科技深蓝体系)

- **配色标准**：
  - 页面背景：`#101924` 搭配科技径向渐变 `#17212D`
  - 卡片容器：`#152438`，内衬背景 `#0E1A29`
  - 品牌主色：经典科技蓝 `#076EE1`，高光辅助亮青色 `#00D2FF`
  - 达成标绿：`#10B981` / `#34D399`，警示红 `#EF4444` / `#FDA4AF`
- **字体与语言**：
  - 字体：全页面强制使用**微软雅黑（Microsoft YaHei）**；
  - 语言：纯规范中文简体字，避免不必要的繁简切换按钮破坏视觉沉浸感。
- **移动端交互**：
  - 手机端最大宽度 680px 居中卡片流；
  - 底部配置悬浮快速导航栏（概览、战报、战略、亮点、反思、协同、剪影），支持单手平滑滚动定位。

## 📸 现场照片 Base64 嵌入红线 (100% 离线免外链)

常规网页引用本地路径（如 `src="照片/01.jpg"`）发给他人后，移动端因无本地文件必然裂图。

本技能内置了 `scripts/embed_event_photos.py` 自动化处理管道：
```bash
python scripts/embed_event_photos.py --photo-dir "<照片目录>" --html-path "<目标HTML路径>"
```

* **自动排序**：按文件名序号（`01.jpg`、`02.jpg`...）升序处理；
* **EXIF 自动纠正**：物理校正手机拍照旋转角度（消除倒置现象）；
* **高清自适应压缩**：限制最大边 1200px、82% 质量 JPEG，单个 HTML 控制在 1.5MB~2MB；
* **纯净画廊大图**：图片下方不堆叠说明文字，保持大气质感。

将本目录（`event-retrospective-report`）复制到对应 Agent 的全局技能目录：


  ```bash

  ```
