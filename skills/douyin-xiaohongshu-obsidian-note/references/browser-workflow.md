# 抖音/小红书平台访问与媒体判断

## 工具适配

此流程描述能力，不绑定某家 Agent API。先发现当前客户端工具，再读取相应文档或技能。已安装且授权的小红书连接器可用，但返回正文、标题、封面不代表已取得全部图片或视频内容。若使用 Agent Reach，可先检查后端状态；它是可选路由，不是本技能依赖。

优先顺序：已授权浏览器的原作品页面 → 已授权、可返回该原帖完整材料的连接器 → 用户提供的原帖截图/视频/字幕。不要为单条转存无故安装爬虫、导出 Cookie、启用调试端口或切换登录账号。浏览器只能在用户授权范围内读页面；不点赞、收藏、评论、关注或发消息。

## 打开与定位

1. 从分享文本提取完整 URL；保留 `xsec_token` 等仅为访问所需的参数，不把签名放入公共文档、终端日志或最终笔记。`sources.py` 输出只有分类与规范化链接，不回显签名。带签名输入优先通过客户端结构化输入或 UTF-8 stdin 传递，避免进 shell 历史。
2. 短链接先在授权浏览器导航，读取最终实际 URL；跳转若不是对应平台原帖域名，则停止。遇到登录/验证码由用户正常完成，不重复重试。不能把短链直接当永久来源或根据标题推测作品。
3. 核对用户给的具体作品，而不是主页作品流、收藏、评论推荐或登录失败页。页面 DOM 可能同时含多个媒体区域；只在当前打开的作品内容容器读取。
4. 记录正文、作者与可确认的发布时间。`08-11` 不足以证明年份；“编辑于 1 天前”是编辑信息，不是发布时间。不能根据电脑日期补年份。标题写“附地址”但正文只有店名/地区时，不虚构街道门牌。
5. 页面提取失败时截图查证，不能用一次空 AX/DOM 结果认定原帖无正文。也不能借机枚举账户其它内容。

## 抖音单条视频

- 确认最终地址是 `www.douyin.com/video/<id>`；用户页或分享落地页要继续定位到用户要求的单条原视频，但不得枚举账号其它作品。
- 页面简介只作为元数据，不能代替口播。可选的 `extract_metadata.py` 只持久化白名单字段，不保存格式直链、Cookie 或请求头。yt-dlp失败后转用已授权浏览器/用户材料，不反复调用一个不支持的提取器。
- 取得视频后进入 [视频取证与清理](video-workflow.md)：字幕/ASR与实际画面共同支撑内容，候选帧需逐张查看。

## 小红书图文与 LIVE

- 记录轮播总数，每次翻页核对页码，待加载完成后读图；结束时比较已查看页码集合与总数。不要用图片 URL 数量当页数，DOM 中可能有预加载、重复节点、头像、广告。
- 对每张原图记录原顺序和所承载的信息：知识卡片、操作步骤、对照/证据、背景装饰。逐张理解后再选择最终插图；选择少于总数时不能遗漏独立要点。
- LIVE 标志及其局部播放控件不等于整条视频贴。静态部分足够时按图文；关键动作仅在 LIVE 动态中出现时查看动态或明确未验证，不能凭一张静态图推断动作。
- 保存原图/大图的已观察 URL 或使用浏览器本身的下载能力。若只能保存截图，尽可能截取内容区，排除评论、账号导航和插件浮层；注明是截图、不是原图。不要放大低清图后谎称高清。
- 保留水印与必要署名，不为规避归属而裁切。正文整理为自己的学习摘要，不无必要复制评论个人信息。

## 小红书视频

此分支必须同时阅读 [视频取证与清理](video-workflow.md)，与抖音视频共用字幕/ASR取证、关键帧筛选和最终清理；下列规则限定小红书平台的访问方式。

- 用当前笔记内的主播放器与时长确认视频，勿相信第三方下载插件汇总的“资源数”。图文与视频同时承载信息则 `mixed`。
- 下载仅限已经观察到、用户可访问的媒体地址；禁止构造签名、破解防盗链、复用未知外站下载器。`fetch_asset.py` 只支持列入代码白名单的公开平台 CDN；其它合法 CDN、blob 或流媒体用当前客户端支持的授权下载/播放能力，不把 blob URL 交给普通 HTTP 下载器。
- 视频下载后用 ffprobe 验证，而不是只看 `.mp4` 扩展名。小红书不是 yt-dlp 必然支持的网站；不得反复后台尝试一个已失败的提取器。
- 原字幕/本地 ASR可作为临时证据。使用云 ASR 前说明将上传视频/音频并取得用户授权；不默认消耗付费 API。ASR错字要结合画面修正，仍存疑则标注。
- 无可靠口播证据，只能写视觉笔记并标注边界。仅标题/封面不构成视频知识笔记；只听口播又不查看画面也不能称为图文分析。
- 均匀抽帧不保证覆盖快速闪现步骤。理解内容后按时间补帧，去除重复镜头/转场/模糊图；每张入选帧写清“支持哪项说明”。默认抽帧宽度不超过 1920 且不放大，必要时用原始分辨率截图。

## 收尾与范围

本技能不收集两平台的主页/收藏列表，不记录个人收藏地址，不检查新增内容，也不根据账号推荐其它作品。设计验证时打开的样本不进入默认配置。保留用户原有浏览器标签；若导航了用户标签，尽量返回原位置，不关闭用户正在使用的标签。仅清理此次工作区，不动下载文件夹中既有文件。
