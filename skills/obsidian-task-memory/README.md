# Obsidian Task Memory

将选定任务或对话保存成“可续接的交接快照 + 按需提取的经验卡”。支持上下文压缩、决策日志、Prompt/代码抽取、避坑记录和只读恢复。已有笔记永不原地修改。

## 安装与使用

将整个 `obsidian-task-memory` 文件夹放入你的 AI 客户端支持的 Skill 目录；加载路径由客户端决定。没有 Skill 机制时，让 AI 阅读 `SKILL.md` 及其按需引用文件即可。技能指令不依赖任何厂商的 API；有文件能力的客户端可以写库，没有文件能力则只能交付正文供手动保存。不能保证每个平台都自动发现技能或读取全部历史。

首次提供库根目录和保存区；不自动安装插件、不修改全局规则。通用默认建议 `任务与经验/`；HaiLan 已选择 `E:\hailan\09 任务与经验\`，详见 [路径设计](references/storage.md)。配置使用当前请求或用户本地配置，不将私人记录和机器凭据放进技能仓库。

可直接说：

- “归档前，把这次任务保存到 Obsidian，留下能给新会话接手的状态和踩坑记录。”
- “只提取这次方案选择的理由和可复用提示词，先给我预览。”
- “这次还没解决，也先保存失败尝试，别把猜测写成根因。”
- “从任务与经验里找上次关于某项目的记录，恢复上下文，先不要继续执行。”
- “读取这份交接笔记，核实当前文件后继续原任务。”

生成归档不等于关闭平台会话；安装 Skill 不等于授权所有会话自动归档。模板里没有的事实不能自动补全。

## 安全写入工具

指令可独立使用；可选工具要求 Python 3.10+ 和 PyYAML 6.x（`requirements.txt`）。按当前环境授权安装依赖，例如在已有虚拟环境运行 `python -m pip install -r requirements.txt`。不自动更改用户的全局 Python。

AI 在库外的临时目录生成一个 UTF-8 JSON 清单；content 是经过语义核对的完整 Markdown 字符串，不是文件名：

```json
{
  "vault_root": "/absolute/path/to/vault",
  "archive_root": "任务与经验",
  "notes": [
    {"path": "会话/2026/09/20260910-100000-任务-a1b2.md", "content": "完整 YAML frontmatter 和 Markdown 正文"}
  ]
}
```

示例 content 仅说明数据结构，实际内容须符合 [笔记契约](references/note-format.md)。Windows 的 JSON 路径用转义反斜杠或正斜杠。notes.path 相对于 archive_root；双链则相对于库根。默认只读预览：

```sh
python scripts/save_notes.py /path/to/manifest.json
```

核对预览的实际路径、全文和返回的 digest；当用户授权及库规则满足后，用同一个摘要提交：

```sh
python scripts/save_notes.py /path/to/manifest.json --apply --expect DIGEST_FROM_PREVIEW
```

摘要绑定库路径、保存区、内容与顺序；不是用户批准凭据，调用者仍负责遵守授权。变更后重新预览。工具拒绝越界路径、符号链接/连接点、Windows 非法文件名、已有不同内容、无效属性和失效正文双链。相同路径相同内容可安全重试。

每页先完整写入临时文件，再以硬链接无覆盖地提交并回读；要求本地文件系统支持硬链接（常见 NTFS/ext4/APFS）。不支持时报告失败，不退化为覆盖写入；可换到受支持的本地库，或由客户端以具备同等保障的新增机制保存。不能把库路径指向不受信任、被并发替换的目录。

多页提交**不是整体事务**：中途失败会列出已提交路径，临时文件只清理本次创建项。保留已生成文件，不删除回滚；相同清单重试可补齐剩余页。正文交叉链接只有整批完成时才能保证全部可用；部分失败需据结果复核。工具不验证事实、敏感信息是否漏出、外链可用性或 Obsidian UI 渲染，这些由执行者检查。

工具只接受库根相对且不带标题/块锚点的正文双链；代码围栏内的 `[[示例]]` 不作链接校验。若需锚点链接，使用更强校验工具或客户端核对，不跳过现有检查冒充通过。

## 验证

```sh
python -m unittest discover -s tests -v
```

覆盖中文读写、默认只读、已有文件保护、清单摘要变化、路径越界与连接点、代码中的双链、断链、非法 YAML、部分失败后的幂等重试。语义场景另见 [行为验收](references/acceptance.md)。

设计参考：用户本地《与Codex长对话一定要有这个习惯.md》的“给无上下文新会话写交接”方法；没有复制文章全文。此次库适配仅分析结构及相关样本，未迁移历史笔记。用户实际对话、工作资料、原文和私有配置不属于分发包。
