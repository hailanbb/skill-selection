# 保存区与适配

## 通用布局

`vault_root` 必须由用户或已核实的本地配置提供。`archive_root` 是库内相对路径，默认建议 `任务与经验`，首次由用户选定；不能将某台机器的路径写死在通用 Skill 中。

```text
任务与经验/
  会话/YYYY/MM/YYYYMMDD-HHmmss-任务短名-唯一后缀.md
  经验/决策/YYYYMMDD-主题-唯一后缀.md
  经验/提示词/YYYYMMDD-主题-唯一后缀.md
  经验/代码/YYYYMMDD-主题-唯一后缀.md
  经验/避坑/YYYYMMDD-主题-唯一后缀.md
```

只创建实际需要的子目录。默认一次一份会话快照，经验卡按需，不为填目录而创建空卡。较短、无后续任务的单条经验可以只建经验卡，在卡内记录充分的来源上下文。

任务第一次保存时生成稳定 `task_id`（例如 `task-20260910-唯一后缀`）；每页另有唯一 `id`。后续会话沿用 task_id，跨平台迁移不改。时间使用带时区 ISO 8601；文件名不含冒号。标题要能检索，唯一后缀仅解决冲突。

正文双链采用**库根相对路径、不含 .md**，如 `[[任务与经验/会话/2026/09/20260910-100000-示例-a1b2|上次交接]]`。只连已有笔记或本次确定将创建的笔记；没有合适目标时用纯文本，不为了双链制造无意义页面。外部产物保留可访问地址；私有会话链接可缺失，不生成分享链接来补来源。

同主题跨个人、工作、研究领域可用 `domain`、`project` 和 tags 区分，不把平台名当主分类。若库已有分类规范，为 category 选适用的既有类别；无匹配则在预览中报告并询问，不改分类文件。保存区路径与来源归档分类目录不是同一回事。

## 扩展时机

先靠文件夹、Properties、tags、搜索和新页双链工作，不依赖 Dataview、Bases、向量数据库或第三方索引。记录增多后，可以单独设计只读检索器；没有搜索能力的客户端让用户提供笔记。批量重构、回链补全、改分类、导入 Wiki 均不属于本技能默认行为。
