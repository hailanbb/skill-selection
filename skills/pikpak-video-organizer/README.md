# PikPak 云端影视极速整理与广告清理工具

基于 PikPak 官方 API 的 15 并发极速影视归档引擎，专为大容量网盘影视资源整理、演员分类、字幕同步与博彩垃圾过滤设计。

---

## 🌟 核心功能

1. **REST API 极速并发**：15 并发批量重命名与原子级批量移动，百部影片仅需数秒。
2. **多级自定义目录寻址**：支持在终端自由选择网盘现有文件夹或输入任意多级自定义路径。
3. **智能番号识别与元数据检索**：
   - 支持标准有码/无码番号（如 `IPX-123`, `MIDV-045`）及 FC2 长编号（如 `FC2-PPV-1234567`）。
   - 自动在线刮削标题与女优名，内置常用女优中日译名映射表（如 `八掛うみ -> 八挂海`）。
   - 优先本地反向嗅探女优名，双重兜底杜绝刮削失败。
4. **严格垃圾与广告过滤**：
   - 严格白名单：视频体积 $\ge 50\text{MB}$ + 合规番号 + 视频格式。
   - 广告黑名单强拦截：对带有博彩特征词（“澳门”、“新葡京”、“威尼斯人”、“台妹子”等）的伪装广告一票否决。
5. **智能防重复与保全**：目标目录同体积影片自动跳过，不同版本自动追加 `_1.mp4` 保全，杜绝数据覆盖。
6. **安全回收站**：垃圾文件与旧目录移入云端回收站，随时可一键还原。
7. **目录保护机制**：绝对豁免目标归档目录与女优专属子文件夹，杜绝误删。

---

## 🚀 快速上手

1. 准备配置文件 `config.json`：
   ```json
   {
     "access_token": "YOUR_PIKPAK_TOKEN",
     "source_folder": "My Pack",
     "target_folder": "女优",
     "concurrency_limit": 15,
     "min_video_size_mb": 50,
     "clean_ads": true,
     "delete_empty_subdirs": true
   }
   ```
2. 双击运行 `PikPak一键极速整理.bat` 即可全自动执行。
