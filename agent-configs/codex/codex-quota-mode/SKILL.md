# Codex 全局省额度模式

用可回滚的配置与规则开关切换模式。开是 Astra/medium + Luna/medium，关是恢复开启前设置，绝不把关硬编码为某个模型。

## 口令与执行

- “开启省额度模式” → `on`；“关闭省额度模式” → `off`；“查询/查看省额度模式” → `status`。单纯咨询、引用、否定或比较这些词不写文件；一句同时要求开和关且先后不明时澄清。
- 先定位本 Skill 安装路径及当前 Codex home（明确配置的 CODEX_HOME，否则用户目录下 .codex）。使用可用的 Python 3.11+ 运行 `scripts/quota_mode.py <on|off|status> --codex-home <绝对目录>`。本 Skill 随附 TOML 编辑依赖，不运行 pip、不下载配置、不输出完整配置或凭据。
- 用户明确开/关即授权本开关管理的六个配置值及 AGENTS.md 受管块；按环境要求申请必要的文件写权限，不重复征求同一动作的业务批准。只创建 Skill 不等于要求开启，默认保留关闭。
- 开启前用 status 查看已知配置。若用户要求“当前会话立即切换模型”，先核实当前工具或界面是否支持；用户可在支持的界面临时调整会话模型或推理强度；仅编辑文件不能改当前运行模型。新会话/重启后加载全局默认，界面、项目、配置 profile、命令行与平台策略可能覆盖它。Skill 不自动升降强度，也不能靠修改文件热切换当前轮。
- 报告区分“已保存全局配置”和“当前会话实际模型”。输出简短状态、目标 Astra/medium + Luna/medium、必要的重新加载提示。不把配置写入成功说成模型已切换，不承诺节省比例。
- 关闭先停止本任务继续派发省额度子任务，让已派任务完成或收回结果；不强杀别的会话或抹掉它们的工作。脚本恢复六个值并撤回受管块，保留期间的其他改动。对受管值被手改等冲突，展示具体键和备份位置，不强制覆盖。
- 脚本返回 pending 时，先按下述恢复规则处理。其他任务不必读取本 Skill 的设计报告。
- 从已开启 v1.0 升级时，先执行旧版 `status`，确认无冲突且不是 `pending`；再执行旧版 `off` 恢复基线，备份并替换为新版。若希望继续启用，再执行新版 `on`。不要直接替换脚本，以免触发 high 配置冲突。
- 脚本 stdout 是 ASCII 转义的 JSON，解析后用中文说明，不把 `\uXXXX` 转义原样贴给用户；这避免 Windows 子进程默认编码导致乱码。

## 开启后的调度

受管规则正文在 [assets/mode-block.md](assets/mode-block.md)，脚本将其追加至全局 AGENTS.md，使新会话即使不再次调用本 Skill 也能按需调度。

- 小改动、短问答、强耦合任务由当前主 Agent 直接做。复杂任务只有当子任务可独立开展、能抵消沟通与重复上下文开销时才委派；不要机械启动五个角色。
- 主 Agent 负责目标、架构、接口/数据/鉴权决策、整合与验收。选择所需角色，而不是创建同名全局角色文件，避免覆盖已有 explorer/worker/reviewer。
- 实际调用可用的 collaboration.spawn_agent 时显式传 `model="gpt-5.6-luna"`、`reasoning_effort="medium"`、`fork_turns="none"`。不要用 full-history fork，它在当前工具中继承主模型且不接受覆盖。不同工具先读实际 schema；无法显式选择时不得宣称用了 Luna。
- 默认最多 2 个并发子 Agent（以平台更低上限为准），子 Agent 不再委派。给每个任务最少上下文、文件所有权、允许操作及完成判据；跨文件依赖按顺序开展，主 Agent 同时推进有用的独立工作，不为空转而派任务。
- 子任务遇到难点先收窄一次；仍失败由主 Agent 接手，不循环重试或偷偷新增 Astra 子 Agent。Luna 不可用/参数不支持时明确说明降级，按风险继续主线程可做的工作，不卡死任务。
- 主 Agent 查关键差异与测试证据，不重做整套子任务。角色汇报只含成果、定位、验证和阻塞，不搬运大日志。无真实 spawn 成功记录就不报告 Luna 参与。
- 可用额度查询工具时仅在用户询问或对照试验时查询；账号用量含其他会话，不能据两个百分比断言本模式省了多少。不购买、重置额度或读取历史聊天来计量。

## 恢复与限制

- `recover` 只回滚中断事务：先 status，确认 pending 且文件仍是记录的 before/after 状态后执行。脚本拒绝覆盖第三方修改。锁文件存在时先核实是否仍有切换进程；不要自动删除锁后重试。
- 状态/原始字节快照位于 `<CODEX_HOME>/quota-mode/`，只留本地，不上传仓库或贴进对话；它们可能包含原配置中的私有内容。回滚不恢复安全设置，因为开关根本不修改它们。
- 非空全局 AGENTS.override.md 会屏蔽本规则，脚本拒绝开启并指出来源；不擅自改覆盖文件。项目级与 UI/profile 覆盖只能提示或按当前任务检查，不能宣称全局开关压过一切。
- 开关是全局默认策略，不是跨设备同步或跨窗口实时广播。旧会话显式查询后可同步行为偏好，实际模型/推理强度仍需宿主重新加载或用户用受支持界面调整。
- 深度依据、文章纠正与测试范围见 [references/design.md](references/design.md)，只在解释设计、维护或用户要求分析时读取。
